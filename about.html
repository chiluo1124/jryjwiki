作品简介

「有人说，世界就是一场巨大的噩梦……」起初没人在意，直到人们醒来时眼前依旧残留着梦的痕迹。灾难席卷而来，现实崩塌殆尽，到最后只剩你我，在旧日的余烬中捡拾人类文明。

都市异能 × 梦境入侵 × 末日群像，偏群像、无系统、不无敌、非爽文。

SITE

网站说明

本站基于《旧日余烬》1-60 章 + 读者信息册整理，随连载持续更新。

技术

纯静态多页面站点（每个模块一个 HTML），零依赖、无需构建。整个站点 = 1 个 CSS + 2 个 JS。部署到 GitHub Pages / Netlify / Vercel 均可，构建留空、发布目录填 . 即可。

如何贡献

编辑 assets/data.js 中的数组（chars / factions / places / items / timeline / chapters / questions）即可增改内容，所有页面自动同步。
